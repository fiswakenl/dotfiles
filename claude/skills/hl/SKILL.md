# hl: пиши так, чтобы читалось

Цель: читатель с первого раза понимает и не спотыкается. Признаки лежат в `features.md` (строка на признак),
постановка для модели - в `prompt.md`. В этом файле их нет: правятся там.

## Порядок

1. **Кто читает и что у него в голове.** Убери то, что он знает, добавь то, чего нет. Есть тексты автора - ориентируйся на них.
2. **Черновик пиши сам**, со структурой из `msg`, если это письмо коллеге.
3. **Предложение правки:** `echo "<черновик>" | uv run ~/.claude/skills/hl/hl.py` (Bash). Скрипт отдаёт переписанный текст по признакам из `features.md`.
4. **Итог собираешь ты, не скрипт.** Сверь предложение с черновиком: смысл, факты, числа, имена и структура целы, ничего не выдумано. Что скрипт испортил, верни; что улучшил, возьми.
5. **Проверки:** вырезание (убери предложение: что потеряет читатель?), перенос (влезет в чужой текст без правок - значит пустое), вслух (где споткнулся, переписать).

Скрипт упал или молчит - собери итог сам по `features.md`.

## Рядом

`msg` задаёт устройство письма коллеге; `hl` отвечает за фразы. Правила `msg` (факты проверенные, без длинных тире) остаются в силе.
