Что изменилось:

!`git status --short`

!`git diff --stat HEAD`

Соседние коммиты — держать их стиль:

!`git log --format='%s' -8`

Куда отправляем:

!`git status -sb | head -1`

Пожелание к сообщению: $ARGUMENTS

## Порядок

1. Из статистики не видно сути — смотрю сам диф: `git diff HEAD`.
2. Сообщение по-русски, одной строкой, как в логе выше: **что стало, а не что я сделал**. Без префиксов вроде `feat:`, без точки в конце. Длинно — двоеточие и вторая половина: «Дек снаружи: обратный туннель через dev».
3. Правки не связаны между собой — раскладываю по нескольким коммитам, а не сваливаю в один.
4. `git add -A`, коммит, затем `git push`. Ветка не отслеживается — `git push -u origin HEAD`.
5. Коммитить нечего, но локальные коммиты не отправлены — просто пушу.
6. Удалёнка ушла вперёд — `git pull --rebase` и пушу снова. Конфликт — останавливаюсь и говорю, руками не разруливаю.
7. Пуш прошёл, репозиторий — `dnk`, и я на маке (`uname -s` → `Darwin`) — подтягиваю копию на сервере:

   ```
   ssh dnk 'cd ~/store/dnk && git pull --ff-only'
   ```

   Не сошлось fast-forward или сервер недоступен — говорю одной строкой и не чиню. Пуш при этом уже состоялся, откатывать нечего.

Ветку не завожу: в этих репозиториях работа идёт прямо в основной.

Хост `dev` не трогаю. `klali` пока тоже не подтягиваю — только `dnk`.

Отчёт — одна строка: хеш, сообщение и куда ушло. Подтянул сервер — добавляю к ней. Диф в ответ не печатаю.
