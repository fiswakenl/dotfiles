Что изменилось:

!`git status --short`

!`git diff --stat HEAD`

Соседние коммиты — держать их стиль:

!`git log --format='%s' -8`

Пожелание к сообщению: $ARGUMENTS

## Порядок

1. Из статистики не видно сути — смотрю сам диф: `git diff HEAD`.
2. Сообщение по-русски, одной строкой, как в логе выше: **что стало, а не что я сделал**. Без префиксов вроде `feat:`, без точки в конце. Длинно — двоеточие и вторая половина: «Дек снаружи: обратный туннель через dev».
3. Правки не связаны между собой — раскладываю по нескольким коммитам, а не сваливаю в один.
4. `git add -A`, коммит. **Не пушу** — для этого `/push`.
5. Коммитить нечего — говорю одной строкой и выхожу.

Ветку не завожу: в этих репозиториях работа идёт прямо в основной.

Отчёт — одна строка: хеш и сообщение. Диф в ответ не печатаю.
