# GV: голос для Claude Code

Говоришь — реплика уходит в окно Claude. Поправка к уже переданному стирает старый ход из истории Claude и отправляет исправленный текст; новая мысль, пока Claude занят, — быстрый вопрос веткой разговора (quick), основная работа не прерывается.

## Адаптеры

| `voice` | Кто слышит | Кто решает: новая мысль, поправка №N, quick | Ответ |
|---|---|---|---|
| `gemini` | Gemini Live | Gemini | читает вслух |
| `deepgram` | Deepgram, потоком — только речь | классификатор Decisions | в окне Claude |
| `openai` | OpenAI, каждый отрезок речи целиком | классификатор Decisions | в окне Claude |

У `deepgram` и `openai` слушает конвейер [Pipecat](https://github.com/pipecat-ai/pipecat): микрофон → Silero VAD → распознавание → конец реплики решают вместе Smart Turn (локально, по интонации) и классификатор законченности Pipecat по тексту — OpenAI Decisions, ~0,2 с, ключ OpenAI: реплика кончается, когда согласны оба; пауза дольше `pause` — реплика закончена и так.

Куда отправить реплику, решает `adapters/router.py`: классификатор OpenAI Decisions (~0,2–0,4 с) видит переданные реплики с состоянием и давностью и отвечает да или нет: продолжает ли реплика последнюю переданную; новая мысль, пока Claude занят, — quick. Текст уходит как распознан, без переписывания. Оркестратор плагина (`hooks/orchestrator.ts`) больше не зовётся.

## Запуск

```zsh
ccg            # Claude с GV и мостом отката (функция в ~/.config/zsh/20-projects.zsh)
/gv            # включить или выключить голос; состояние — ~/.claude/gv.state
/gv deepgram   # сменить адаптер на лету; выбор запоминается в ~/.claude/gv.voice
```

`ccg` = `--plugin-dir ~/.claude/gv` + `BUN_OPTIONS=--preload=…/preload.mjs`. Preload нужен мосту: штатный API плагина не даёт откатить историю.

Адаптер по умолчанию — настройка `voice` плагина («Голосовой адаптер» в `/config`); `/gv <имя>` выбирает поверх неё, запоминает в `~/.claude/gv.voice` и сразу перезапускает сервис, сессия остаётся.

Ключи: Gemini — `~/.config/gemini.env` (только через прокси из этого файла), Deepgram — `~/.config/deepgram.env`, OpenAI — `~/.config/openai.env` (через `OPENAI_PROXY` или `HTTPS_PROXY`).

## Как устроено

- `core.py` — вся логика: запросы, поправки, реплики на решение оркестратору, очередь речи. Правила — в его шапке.
- `voice.py` — сервис: запуск, выбор адаптера и HTTP-ручки (список — в его шапке); `page.html` — страница журнала.
- `overlay.swift` — плашка поверх экрана (мак): последние сообщения сессии пузырями, одна кнопка — свернуть; `voice.py` собирает её в `.build/` и поднимает, когда узнал сессию.
- `adapters/` — голосовые адаптеры, файл на адаптер:
  - `__init__.py` — общий интерфейс `Adapter` и выбор по имени;
  - `gemini.py` — Gemini Live: сокет, колонки, вызовы функций; `mic.py` — его микрофон по репликам;
  - `recognizer.py` — конвейер Pipecat у адаптеров распознавания: микрофон, Silero VAD, Smart Turn, законченная реплика — в ядро;
  - `deepgram.py`, `openai.py` — их сервисы распознавания в конвейере;
  - `text.py` — замена Gemini без звука и сети для тестов (`GV_TEXT_ONLY=1`).
- `prompts/gemini.md` — инструкция Gemini; `prompts/orchestrator.md` — правила оркестратора.
- `hooks/register.ts` — плагин: забирает работу `/next` — ask шлёт в окно Claude через мост (командами `/call` сервиса), quick — веткой разговора, реплику на решение — оркестратору; ответ — `/answer`. О каждом ходе Claude, и набранном руками, сообщает сервису: пока ход идёт, новый ask ждёт в ядре. Номера запросов — номера одного запуска сервиса (заголовок `X-GV-Epoch`): после перезапуска плагин их забывает, а сервис отвергает старые.
- `hooks/orchestrator.ts` — промпт оркестратора и разбор его решения, без обращений к движку.
- `preload.mjs` + `native/bridge.mjs` — мост в окно Claude: `status`, `list`, `send`, `rewind`. Сокет `$TMPDIR/gv-UID/PID.sock`, свой у каждого процесса.

## Снаружи

Один вход — `POST /call {"name", "args"}`, имена те же, что у Gemini и моста:

```sh
curl -s localhost:8790/call -d '{"name":"ask","args":{"text":"Что в todo?"}}'
curl -s localhost:8790/call -d '{"name":"utter","args":{"text":"Что в todo?"}}'   # как реплика адаптера распознавания
curl -s localhost:8790/call -d '{"name":"rewind","args":{"target":1}}'
curl -s localhost:8790/call -d '{"name":"list"}'                              # мост: сообщения в окне Claude
```

## Проверки

```sh
uv run --script ~/.claude/gv/tests/sim_test.py   # все сценарии на ядре, пара секунд
uv run --script ~/.claude/gv/tests/recognizer_test.py  # конвейер Pipecat: речь из say, распознавание ненастоящее, без сети
claude plugin test ~/.claude/gv                  # оркестратор и плагин вокруг ненастоящего сервиса
uv run --script ~/.claude/gv/tests/run.py        # сценарии Gemini на живом ccg в tmux, без голоса, ~3 мин
```

Сценарии — данными в `tests/scenarios.py`; решения оркестратора в них заданы сценарием, модель не зовётся. Голос, микрофон и колонки тесты не трогают.

Мост — внутренний механизм, проверен на Claude Code 2.1.319, macOS arm64: после обновления Claude preload может потребовать правки.
